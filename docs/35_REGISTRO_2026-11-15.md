## 5. Como rodar
```
SULCO_PREAQUECER=0 .venv/Scripts/python -m uvicorn src.api.main:app --port 8000     # API (1ª chamada do plano ~8 s)
cd web && npm install && npm run dev                                                 # http://localhost:5173 (o Vite escuta em localhost/IPv6; proxy /api -> :8000)
```
Quiz: `/boas-vindas`; painel: `/?topico=semeadura`; chat: `/maira?de=semeadura`. O perfil do quiz fica no `localStorage` (`sulco:perfil`). Na suíte, a IA é desligada (`tests/conftest.py`); **não** chamar a DeepSeek em teste.

## 6. Armadilhas encontradas
- A API em execução não recarrega o código: depois de mudar `src/`, reiniciar o uvicorn (um erro "Não consegui montar esta etapa" foi a API antiga recusando o pedido novo).
- Texto longo com aspas em `bash`/heredoc quebra o terminal: gravar arquivos com a ferramenta de escrita.
- Testes que só checavam `file://` deixaram passar `data/culturas/x.csv` na fonte do ciclo (visto na tela real): a limpeza agora é geral (`etapas.limpar_caminhos`) e há teste em todas as 16 culturas.
- `pdftotext` no Windows usa Latin-1 por padrão: usar `-enc UTF-8`.
